打开 Library

Phase C：Library 二级入口为 All / Categories / Favorites / Recent / Updates / Missing / Archive / Scan Changes；三视图共享搜索筛选。文件全文搜索可试关键词 PHASEC_FILE_SEARCH_MARKER（命中 pr-review 包内 checklist.md）。

Phase D：完整 Skill Detail（Overview / Files / Instances / Source / Permissions / Usage / Activity / Snapshots）。建议验收：pr-review（多实例·文件树·二进制·嵌套 SKILL.md·部分归因）、api-doc（Update Available）、demo-path-missing（Relink）、demo-codex（Usage 暂无数据）、commit-format（部分 Missing）。

Phase E：多文件 Editor / Diff / Conflict。验收路径：只读 Editor；pr-review 多文件草稿；正常应用；外部冲突（SP.loadEditorDemoCase('external-content')）；合并；强制覆盖；部分失败回滚（apply-partial-fail）。打开 Editor 前请带 ?dev=1。
