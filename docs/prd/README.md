# Skill Panel PRD 5.0 原型重构交付包

本交付包用于把现有 HTML 原型从“指定目录下的本地 Skill 文件维护工具”重构为 Skill Panel 1.x：本地优先的 Skill Manager。

## 使用顺序

1. 将 `PRD5.0.md`、现有全部 HTML、`shared.css`、`shared.js` 与本目录一起放入 Agent 工作区。
2. 先发送 `05-Agent主提示词.md`，要求 Agent 完成仓库审计并建立重构基线。
3. 按 `06-分阶段执行提示词.md` 逐阶段执行，不要一次性要求 Agent 重写全部页面。
4. 每完成一个阶段，使用 `07-验收清单.md` 验收。
5. 最后使用 `08-回归测试用例.md` 完成核心流程回归。

## 文件说明

- `01-原型重构实施方案.md`：改造目标、优先级、阶段和交付要求。
- `02-信息架构与页面规格.md`：页面清单、导航、页面结构和关键交互。
- `03-数据模型与状态机.md`：原型统一状态源、对象关系和状态机。
- `04-旧原型迁移映射.md`：现有文件保留、重写、新增和下线策略。
- `05-Agent主提示词.md`：首次发给 Agent 的总任务提示词。
- `06-分阶段执行提示词.md`：每一阶段可直接复制给 Agent 的提示词。
- `07-验收清单.md`：产品、交互、状态、视觉与工程验收。
- `08-回归测试用例.md`：核心用户流程和异常状态测试。

## 本次改造边界

- 只做 Skill Panel 1.x，界面只围绕 Skill 展开。
- 覆盖发现、浏览、搜索、分类、分析、编辑、安装、更新和管理。
- 不在应用内执行 Skill。
- 不建设 Skill 商店。
- 不引入 AI 自动生成、删除或修改 Skill。
- 不自动执行安装脚本、依赖安装或初始化命令。
- 原型允许使用模拟数据，但模拟结果必须确定、可复现、可验证，禁止使用随机数决定业务结果。
