# 扫描安全边界

## 当前裁决

PRD 5.0 描述全盘发现扫描。该能力涉及隐私、系统权限、性能、敏感目录与路径逃逸，仍需独立
安全裁决。当前生产基础禁止实现全盘扫描。

## 后续评审必须回答

- 首次授权文案与操作系统权限如何对应。
- 默认允许根目录和明确排除目录。
- 系统保护目录、密钥目录、浏览器配置、邮件、照片和云盘的处理。
- 隐藏目录、依赖目录、Git 仓库和构建产物的资源上限。
- 符号链接、挂载点、网络卷和循环路径策略。
- 文本大小、二进制哈希、编码和压缩包限制。
- 暂停、取消、恢复与崩溃后的临时结果清理。
- Formal Index、Scan Result、Change Set 的事务隔离。
- 路径、错误和诊断脱敏。

## 允许的基础测试

- 只使用测试创建的独立临时目录。
- fixture 不包含真实用户路径、正文或凭据。
- 测试结束按测试框架的临时目录生命周期清理。
- 任何扫描实现都需要允许根目录参数，禁止使用 home、文件系统根目录或自动发现的宽泛路径。

## 禁止项

- 启动时自动扫描。
- 后台周期扫描或持续监听。
- 未授权访问 home 或系统根目录。
- 跟随符号链接离开允许根目录。
- 扫描结果直接覆盖 Formal Index。
- 将不可读目录静默视为 Missing。
- 将用户分类、标签、收藏、权限或来源绑定当作扫描结果覆盖。
