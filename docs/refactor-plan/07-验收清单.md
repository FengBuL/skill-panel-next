# Skill Panel 1.x 原型验收清单

## 1. 产品范围

- [ ] 界面只围绕 Skill 展开。
- [ ] 不提供应用内执行 Skill。
- [ ] 不出现 Skill 商店主流程。
- [ ] 不使用 AI 自动改写或自动删除 Skill。
- [ ] 安装不自动执行脚本、依赖或初始化命令。
- [ ] New Skill 不作为主操作。

## 2. 数据模型

- [ ] Skill 使用永久 UUID。
- [ ] Skill 与 Instance 分离。
- [ ] Instance 与 File 分离。
- [ ] 一个 Skill 可聚合多个实例。
- [ ] 一个实例可包含多个文件。
- [ ] SourceBinding、PermissionGrant、ScanSession 和 ChangeSet 独立存在。
- [ ] Draft 绑定实例与文件。
- [ ] Snapshot 可区分文件和完整包。
- [ ] 读取函数不会丢失字段。
- [ ] 写入函数修改真实 state，不修改临时副本。

## 3. 扫描

- [ ] 首次扫描前有授权和隐私说明。
- [ ] 扫描默认只读。
- [ ] 支持暂停、继续和取消。
- [ ] 单目录失败不终止全部扫描。
- [ ] 扫描中保留旧 Library。
- [ ] 扫描结果进入 Change Set。
- [ ] 未确认前不替换 Formal Index。
- [ ] 支持逐项、按类型和全部确认。
- [ ] 可查看文件 Diff、哈希和二进制变化。
- [ ] 用户分类、标签、收藏、权限和来源绑定不会被扫描覆盖。

## 4. Library

- [ ] 默认进入全部 Skill。
- [ ] 有收藏、最近使用、可更新、Missing、Archive 和扫描变化入口。
- [ ] 来源宿主作为筛选。
- [ ] 表格、卡片、目录树三种视图可用。
- [ ] 三视图切换不丢失状态。
- [ ] 多实例默认聚合并可展开。
- [ ] 搜索覆盖 Skill 包文本文件。
- [ ] 全文命中显示文件和上下文。
- [ ] 0 次和暂无数据视觉语义不同。
- [ ] Missing、Archive、Local Modified、Update Available、Read-only 等状态可识别。

## 5. Detail 和文件

- [ ] 展示完整 Skill Package 文件树。
- [ ] 展示主实例和全部实例。
- [ ] 展示来源绑定、版本和官方基线。
- [ ] 展示权限、健康、本地修改和更新状态。
- [ ] 文本文件可查看。
- [ ] 二进制文件显示元数据。
- [ ] 嵌套 SKILL.md 有特殊标记。
- [ ] 可以复制调用方式和路径。
- [ ] Missing 可以 Relink。

## 6. 编辑和安全

- [ ] 无写权限时不可应用更改。
- [ ] 写入前展示目标实例和路径。
- [ ] 草稿刷新后仍保留。
- [ ] 保存前重新校验磁盘状态。
- [ ] 编辑前创建必要快照。
- [ ] 支持文件快照和完整包快照。
- [ ] 外部冲突不会静默覆盖。
- [ ] 支持双向和三方 Diff。
- [ ] 强制覆盖前有完整包快照和专用确认。
- [ ] 写入失败后草稿仍存在。

## 7. 安装和更新

- [ ] 支持 GitHub、Git、ZIP 和本地来源。
- [ ] 安装前展示文件清单和风险。
- [ ] 可选择目标宿主和目录。
- [ ] 安装前检查重复、多实例和冲突。
- [ ] 安装支持部分失败结果。
- [ ] 来源绑定和官方基线可见。
- [ ] 可检查更新。
- [ ] 更新前展示 Diff。
- [ ] 本地修改不会静默丢失。
- [ ] 更新失败可以回滚。
- [ ] 多实例可统一或独立更新。
- [ ] 卸载可选择保留本地副本。

## 8. Insights、Activity、Settings

- [ ] Insights 有 Dashboard、Pending、Suggestions。
- [ ] Unknown / No Data 独立展示。
- [ ] Activity 不默认展示普通调用记录。
- [ ] AuditEvent 不因“处理”被改写。
- [ ] PendingTask 可解决、忽略或延后。
- [ ] Settings 覆盖扫描、权限、快照、更新、生命周期和诊断。
- [ ] Activity 支持 180 天保留和导出设置。

## 9. 视觉和工程

- [ ] 公共 Token 和组件只在 `shared.css` 定义。
- [ ] 页面内无重复公共 `.btn`、`.card`、`.modal` 等定义。
- [ ] 小窗口快速详情不会直接消失。
- [ ] 状态不只依赖颜色。
- [ ] 图标按钮有可访问名称。
- [ ] 动态本地内容已转义。
- [ ] 不使用随机数决定业务结果。
- [ ] 不使用原生 `confirm()` 代替高风险流程。
- [ ] 中英文切换不会产生大量混杂；若未完成则隐藏语言切换。
- [ ] 所有页面可从入口点击到达并正确返回。
