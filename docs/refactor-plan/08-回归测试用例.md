# Skill Panel 1.x 原型回归测试用例

## TC-01 首次扫描并建立 Library

前置：无正式索引。

步骤：进入首次启动页，授权扫描，查看扫描进度，暂停，继续，等待扫描完成，进入变化中心，接受全部变化。

预期：扫描未确认前 Library 为空或保持旧索引；确认后正式 Library 建立；扫描失败目录可查看。

## TC-02 后续扫描保持旧索引

前置：正式 Library 已有数据。

步骤：启动重新扫描，在扫描中返回 Library，查看临时标记，完成扫描但不确认。

预期：旧 Skill 仍可查看；新增和修改只显示待确认标记；正式内容未被替换。

## TC-03 多实例聚合

前置：同一 Skill 有 Claude Code 和 Codex 两个实例。

步骤：在 Library 查看表格、卡片和目录树，展开实例，进入 Detail。

预期：Library 默认只显示一个 Skill；实例数量为 2；Detail 可切换主实例和查看各实例状态。

## TC-04 全文搜索

步骤：搜索只存在于某个参考文件正文中的关键词。

预期：搜索命中对应 Skill，显示命中文件名和上下文；三种视图结果一致。

## TC-05 暂无数据与零使用

前置：一个 Skill 有可靠数据且近 30 天为 0；另一个 Skill 的宿主不支持使用数据。

预期：前者显示“0 次”，后者显示“暂无数据”及原因，筛选和排序不会混为一类。

## TC-06 只读编辑授权

步骤：打开只读实例的 Editor，修改内容，尝试应用，申请单 Skill 写权限，再应用。

预期：无权限时只能保存草稿；授权后可进入 Diff；应用前展示目标路径和快照。

## TC-07 外部修改冲突

步骤：编辑 Skill 后模拟磁盘内容变化，点击应用。

预期：不能直接覆盖；进入三方冲突页；可重新加载、保留草稿、合并、另存为或强制覆盖。

## TC-08 安装 GitHub Skill

步骤：输入固定 GitHub URL，解析来源，查看文件清单，选择两个宿主，确认安装。

预期：不执行脚本；显示来源绑定和官方基线；两个实例归属于一个 Skill；部分失败时逐项展示结果。

## TC-09 更新含本地修改的 Skill

步骤：检查更新，选择可更新 Skill，查看三方 Diff，选择自定义文件更新。

预期：本地修改不会静默丢失；更新前有完整包快照；失败可回滚。

## TC-10 重复组转多实例

步骤：打开重复候选，查看判断依据，将两项确认为同一 Skill 的多实例。

预期：两个旧 Skill 聚合为一个永久 UUID Skill，保留两个实例；分类、标签和历史按确认规则保留。

## TC-11 Missing Relink

步骤：打开 Missing Skill，选择 Relink，指定新路径，查看匹配依据并确认。

预期：保留原 Skill UUID 和历史；实例恢复为 Available；不新建重复 Skill。

## TC-12 Archive 与恢复

步骤：归档一个多实例 Skill 的单个实例，再恢复到目标宿主。

预期：其他实例不受影响；归档前有快照；恢复路径冲突时提供改名、取消或受控覆盖。

## TC-13 卸载并保留副本

步骤：卸载一个宿主实例，选择保留本地副本。

预期：宿主实例被移除，本地副本仍可在 Library 管理；来源绑定处理结果明确。

## TC-14 Activity 审计

步骤：完成扫描、授权、编辑、安装、更新失败、回滚和归档。

预期：Activity 包含上述管理事件；普通搜索、查看详情和复制路径不记录；事件事实不可改写。

## TC-15 页面返回状态

步骤：在 Library 设置搜索、筛选、卡片视图和选中项，进入 Compare，再进入 Detail，连续返回。

预期：最终恢复原搜索、筛选、视图、选中项和滚动位置。

## TC-16 动态内容安全

步骤：演示 Skill 名称或描述包含 HTML 标签和事件属性文本。

预期：界面显示为普通文本，不执行 HTML 或脚本。
