# Skill Panel 1.x 信息架构与页面规格

## 1. 一级导航

一级导航固定为：

- Library
- Insights
- Activity
- Settings

Library 是默认入口和核心工作区。来源宿主、磁盘路径和安装方式只作为筛选或详情属性，不作为一级或主要二级导航。

## 2. Library 二级导航

建议侧栏结构：

```text
Library
├─ 全部 Skill
├─ 收藏
├─ 最近使用
├─ 可更新
├─ Missing
├─ Archive
├─ 扫描变化
│
├─ 分类
│  ├─ 内置分类
│  ├─ 自定义分类
│  └─ 自定义子分类
│
└─ 已保存筛选（可选）
```

宿主、位置、来源、权限、健康、本地修改、数据可信度等进入筛选面板。

## 3. 页面清单

### 3.1 `onboarding.html`：首次启动与扫描授权

必须展示：

- 产品用途。
- 将读取的内容。
- 本地优先和隐私说明。
- 全盘发现扫描的范围。
- 扫描只获得读取能力。
- 写入权限将在编辑、更新等操作时单独申请。
- 开始扫描、稍后设置。

关键状态：未授权、已授权、系统权限不足。

### 3.2 `scan.html` 或全局扫描层

必须展示：

- 扫描状态。
- 当前目录。
- 已访问目录数量。
- 已发现 Skill 数量。
- 失败目录数量。
- 临时发现结果。
- 暂停、继续、取消。
- 查看失败目录。

扫描期间允许进入旧 Library。扫描结束后进入扫描变化中心。

### 3.3 `scan-changes.html`：扫描变化中心

变化分组：

- 新增。
- 内容变化。
- 路径变化。
- Missing 候选。
- 文件删除。
- 健康状态变化。
- 重复关系变化。
- 多实例关系变化。
- UUID 重绑定候选。

每项支持：接受、忽略本次、稍后处理、查看详情。

详情支持：文件树、文本 Diff、哈希、二进制元数据和匹配依据。

顶部支持：按类型全部接受、全部确认、保留未确认项。

### 3.4 `index.html`：Library

顶部：

- 页面标题和当前范围。
- 扫描状态入口。
- 待确认变化数量。
- 可更新数量。
- Missing 数量。
- 重复组数量。
- 安装 Skill 主按钮。

工具栏：

- 全文搜索。
- 筛选。
- 排序。
- 表格 / 卡片 / 目录树切换。
- 列设置。
- 批量选择。

表格推荐默认字段：

- 名称与描述。
- 分类。
- 实例数量 / 宿主。
- 最近使用。
- 调用次数。
- Token / 数据可信度。
- 版本与更新。
- 权限。
- 状态。

卡片视图：突出名称、描述、分类、宿主、最近使用、状态和更新。

目录树视图：按磁盘或宿主层级展示实例位置，Skill 实体可跨位置聚合。

右侧快速详情：

- 名称、描述、分类、标签、收藏。
- 权限和健康。
- 使用、会话、Token、可信度。
- 主实例、宿主、版本、来源、实例数量。
- 调用方式、复制路径、打开宿主。
- 编辑、更新、归档等快速操作。

### 3.5 `skill-detail.html`：完整详情

页面顺序：

1. 顶部概要。
2. 使用与数据可信度。
3. 来源与实例。
4. Skill 说明和调用方式。
5. Skill Package 文件树与文件内容。
6. 更新、本地修改和版本。
7. 权限。
8. 快照与 Activity。
9. 生命周期操作。

顶部操作：编辑、复制调用方式、在宿主中打开、打开目录、更新、更多。

实例面板支持：

- 设置主实例。
- 展开单实例。
- 查看版本、路径、权限和健康。
- 独立编辑。
- 同步到其他实例。
- Relink Missing 实例。

### 3.6 `skill-editor.html`：文件查看与编辑

布局建议：

- 左侧：Skill Package 文件树。
- 中间：当前文本文件编辑区。
- 右侧：Preview、结构、元数据、Diff、问题。

顶部必须显示：

- 当前文件。
- 当前实例。
- 只读 / 可写权限。
- 草稿状态。
- 磁盘同步状态。
- 保存范围。

操作：保存草稿、查看 Diff、创建文件快照、创建完整包快照、应用更改。

### 3.7 `conflict.html`：Diff 与冲突处理

支持：

- 草稿与当前磁盘双向 Diff。
- 官方基线 / 本地磁盘 / 当前草稿三方 Diff。
- 重新加载磁盘。
- 保留草稿。
- 手动合并。
- 另存为新 Skill。
- 强制覆盖。

强制覆盖前展示目标路径、影响文件、快照状态和不可逆风险。

### 3.8 `compare.html`：重复组和多实例判断

不能只提供左右保留。

支持：

- 重复判断依据。
- 名称、来源、仓库、文件结构、内容哈希和 SKILL.md 差异。
- 任意数量候选。
- 确认为同一 Skill 的多实例。
- 保留为独立 Skill。
- 归档某个实例。
- 人工合并为新 Skill。
- 忽略本次重复建议。

### 3.9 `install.html`：安装向导

步骤：

1. 选择来源：GitHub、Git URL、ZIP URL、本地目录、本地 ZIP。
2. 解析和校验来源。
3. 展示 Skill 包和风险。
4. 选择目标宿主和目录。
5. 检查重复、多实例和冲突。
6. 用户确认。
7. 安装进度。
8. 成功、部分成功或失败结果。

不得自动执行安装脚本、依赖安装或初始化命令。

### 3.10 `update.html`：更新与三方差异

展示：

- 当前版本和远程版本。
- 官方基线。
- 本地修改状态。
- 文件变更摘要。
- 文本 Diff 和二进制变化。
- 完整更新或自定义更新。
- 更新实例范围。
- 更新前快照。
- 冲突和回滚。

### 3.11 `uninstall.html`：卸载和移出宿主

选项：

- 从一个宿主卸载实例。
- 从全部宿主卸载。
- 保留本地副本。
- 移出宿主目录。
- 同时解除来源绑定。
- 保留历史、分类和快照。

存在本地修改时必须单独确认。

### 3.12 `insights.html`

标签页：

- Dashboard。
- Pending。
- Suggestions。

Dashboard：总量、Active、Missing、Archive、最近使用、调用、会话、Token、趋势、宿主分布、分类分布、数据覆盖率。

Pending：文件问题、冲突、重复、更新失败、未完成草稿等。

Suggestions：归档候选、重复整理、Token 关注等规则建议。

### 3.13 `activity.html`

只记录管理和审计事件：

- 扫描。
- 变化确认。
- 授权。
- 编辑。
- 快照。
- 安装。
- 更新。
- 回滚。
- 归档。
- 恢复。
- 卸载。
- 删除。
- 失败和退出码。

逐 Skill 调用记录放在 Detail 和 Insights，不默认塞入 Activity。

### 3.14 `settings.html`

二级设置：

- 扫描与发现。
- Library。
- 权限。
- 数据来源与隐私。
- 快照与存储。
- 安装与更新。
- 生命周期。
- Activity 与诊断。
- 外观与语言。

### 3.15 `cases.html`

只用于开发和测试。默认不出现在正式导航中，通过开发模式或 URL 进入。

## 4. 页面间关键跳转

```text
Onboarding → Scan → Scan Changes → Library
Library → Quick Detail → Detail
Library / Detail → Editor → Diff / Conflict → Detail
Library → Install → Install Result → Detail
Library / Detail → Update → Conflict / Result → Detail
Library / Insights → Duplicate Group → Compare → Detail / Library
Library Missing → Relink → Scan Change Confirmation → Detail
Detail → Uninstall → Result → Library / Detail
```

## 5. 响应式和桌面窗口

- 默认按桌面窗口设计，最小有效宽度建议 960px。
- 小窗口时右侧快速详情改为抽屉，不能直接消失。
- 编辑器小窗口时文件树和右侧面板可折叠。
- 不在网页中重复绘制与真实桌面壳冲突的窗口标题栏；如果保留模拟标题栏，应集中在共享组件中。
